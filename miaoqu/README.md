# 秒取 · 短视频下载

粘贴分享链接，解析后直接保存到手机。纯前端 PWA，解析走第三方公开接口，不经过自己的服务器，也不收集账号信息。

## 启动

```bash
cd miaoqu
python3 serve.py        # 默认 http://127.0.0.1:8770/
```

手机与电脑连同一个 Wi-Fi，用终端里打印的 `http://<局域网IP>:8770/` 打开。

> 局域网 HTTP 下可以正常解析和保存，但浏览器不开放剪贴板读取（需长按输入框粘贴），也无法注册 Service Worker。要完整安装 PWA、离线打开和安卓分享目标，请用 HTTPS 地址访问（见下方「部署到 HTTPS」）。

## 装成 App

- **iPhone**：Safari 打开 → 分享 → 「添加到主屏幕」。
- **安卓**：Chrome / Edge 打开（需 HTTPS）→ 菜单 → 「安装应用」或「添加到主屏幕」。
- 安卓从抖音/快手点「分享 → 更多 → 秒取」，可直接带着链接打开并自动解析（依赖 `share_target`，需 HTTPS 且已安装为 PWA）。

## 部署到 HTTPS

整个应用是纯静态文件，`miaoqu/` 目录上传到任意静态托管即可：

- GitHub Pages / Cloudflare Pages / Netlify：把 `miaoqu/` 作为站点根目录发布。
- 已有服务器：把 `miaoqu/` 放到站点子目录，Nginx 需为 `.webmanifest` 返回 `application/manifest+json`。
- 想继续在本地用 HTTPS：`cloudflared tunnel --url http://127.0.0.1:8770` 之类的临时隧道即可获得可安装的地址。

## 平台支持情况

| 平台 | 状态 | 说明 |
| --- | --- | --- |
| 抖音 | 可用 | 公共接口解析，视频直链可跨域下载 |
| 快手 | 可用 | 公共接口解析，视频直链可跨域下载 |
| 小红书 | 受限 | 公开接口需要带 `xsec_token` 的完整链接，且常提示「登录已过期」；可接自建服务 |
| 微信视频号 | 受限 | 没有公开网页下载能力，必须微信登录态；失败会明确提示 |
| 视频直链 | 可用 | 粘贴 `.mp4` 等直链直接保存 |

解析失败时会给出中文原因，不会静默卡住；所有提示都可以追溯到具体环节。

## 保存行为

- **安卓 / 桌面**：Blob + `<a download>`，文件落到「下载」目录。
- **iPhone**：`navigator.share({ files })` 调起系统分享面板，选「存储视频 / 存储图像」进相册。可在设置里改成直接下载到「文件」。
- 视频 CDN 不允许跨域时会自动打开原视频，提示长按保存。

## 设置

- **解析引擎**：自动 / 只用公共接口 / 只用自定义服务。
- **自定义解析服务**：填 `https://your-host/api/v1/parse`，自动拼 `?url=`；支持 `{url}` 占位符；可选 `X-API-Key`。
  兼容 media-parser 风格返回：`{ code: 200, data: { title, video_url, images, author } }`。
  小红书、视频号想稳定可用，就在自己的机器上跑一个带 Cookie 的 media-parser，再把地址填进来（需允许跨域）。
- **iPhone 保存**：系统分享面板 / 直接下载。

历史与设置只存在本机 `localStorage`，可一键清除。

## 文字提取（云端转写）

- 解析成功后点结果页「提取文字」，浏览器把音轨转成 16 kHz 单声道 WAV，直传硅基流动识别，不需要自建服务器。
- 先在 设置 → 云端转写 填自己的硅基流动 API Key（只存在本机浏览器），可点「测试密钥」验证。
- 识别结果可复制或存成 `.txt`。限制：视频不超过 5 分钟；提取时音频会上传到硅基流动。

## 文件

```
miaoqu/
├─ index.html            界面
├─ styles.css            样式
├─ app.js                解析、下载、历史、设置、云端转写
├─ manifest.webmanifest  PWA 清单（含 share_target）
├─ sw.js                 离线外壳缓存（不缓存视频）
├─ serve.py              本地静态服务
└─ icons/                应用图标 192/512/180
```

## 注意

- 公共接口有频率限制，失败属正常，稍后再试或填自定义服务。
- 分享链接会过期，解析后请尽快保存。
- 请只保存你有权使用的作品，尊重平台与作者版权。
