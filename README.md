# 个人工作台

> 集成飞书日程、AI 新闻简报、个人知识库的一站式工作台

## 快速开始

```bash
cd ~/Documents/工作台
./start.sh
```

浏览器会自动打开 `http://localhost:8765`，工作台即可使用。

> **首次使用**：日程与待办功能依赖飞书授权。若页面提示「飞书未授权」，请在终端运行一次：
> ```bash
> lark-cli config init --new
> ```
> 按提示在浏览器中完成飞书登录授权即可。

## 功能模块

### 1. 飞书日程
- **创建日程**：填写标题、时间、描述，点击创建即同步到飞书日历
- **关联日历类型**：支持选择目标日历（主日历 / 共享 / 谷歌 / 会议室 / Exchange 等），点击「同步日历」拉取飞书日历列表，新建日程可指定写入哪个日历
- **今日日程**：自动加载今日飞书日程，日程标题旁标注所属日历类型（非主日历显示标签），点击可加入视频会议
- **一键跳转**：快速打开飞书日历网页

### 2. 待办事项
- **新建待办**：输入待办内容（可选截止日期），回车或点击「添加」即可创建飞书任务
- **未完成列表**：自动加载分配给我的未完成待办，展示截止时间（逾期/紧急高亮）
- **一键完成**：点击待办左侧勾选框即可标记完成，并同步到飞书任务中心
- **任务中心跳转**：快速打开飞书任务网页查看全部任务

### 3. AI 新闻简报
- 每日抓取主流平台 AI 相关新闻（36kr、机器之心、量子位、InfoQ、极客公园）
- 自动过滤 AI 相关内容并分类标注
- 点击「刷新新闻」按钮即可在线抓取最新资讯

### 4. 个人知识库
- **公共知识库**：通用资料、学习方法、工具技巧、行业报告
- **项目知识库**：按项目分类的技术方案、需求文档、会议纪要
- 基于飞书云空间 Wiki，直接在飞书中管理文档

## 使用方法

### 启动工作台
```bash
./start.sh
```
启动后浏览器自动打开，工作台自动加载今日飞书日程。

### 创建飞书日程
1. 在工作台左侧填写日程标题、开始/结束时间、描述
2. （可选）在「日历类型」下拉中选择目标日历；如列表未加载，点击「同步日历」拉取飞书日历列表
3. 点击「创建飞书日程」
4. 日程直接同步到所选飞书日历，无需额外操作

### 查看/加入今日会议
- 工作台自动加载今日日程列表
- 日程标题旁会标注所属日历类型（非主日历显示标签）
- 点击日程条目可直接加入飞书视频会议

### 管理待办事项
- **新建待办**：在待办面板输入内容（可选截止日期），回车或点击「添加」
- **完成待办**：点击待办左侧勾选框，标记完成并同步到飞书任务中心
- **查看全部**：点击「任务中心 →」跳转飞书任务网页

### 刷新 AI 新闻
- 点击工作台中间「刷新新闻」按钮
- 系统自动抓取最新 AI 资讯并更新页面

### 设置每日自动刷新（可选）
```bash
crontab -e
# 每天早上 8:00 自动抓取新闻
0 8 * * * cd ~/Documents/工作台 && python3 fetch_news.py
```

## 依赖
- **lark-cli**：飞书命令行工具（日程、日历列表、待办任务的创建与查询）
- **Python 3**：服务器运行与新闻抓取
- **现代浏览器**：Chrome / Safari / Firefox

## 技术架构

```
浏览器 (index.html)
    ↓ fetch API
本地服务器 (server.py :8765)
    ↓ subprocess
lark-cli (飞书 API)
    ↓ HTTPS
飞书云服务
```

工作台通过本地 Python 服务器代理调用 lark-cli，实现飞书日程/日历/待办的创建与查询，无需在浏览器中暴露 API 密钥。

### API 端点

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/health` | 健康检查 |
| GET | `/api/agenda` | 获取今日飞书日程 |
| GET | `/api/calendars` | 同步飞书日历类型列表 |
| POST | `/api/event` | 创建飞书日程（可指定 `calendar_id`） |
| GET | `/api/tasks` | 获取我的未完成待办 |
| POST | `/api/task` | 创建待办任务（`summary` / `due`） |
| POST | `/api/task/complete` | 完成待办任务（`task_id`） |
| GET | `/api/news` | 获取新闻数据 |
| POST | `/api/refresh-news` | 刷新新闻 |
